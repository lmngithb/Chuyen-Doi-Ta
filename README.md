# Chuyện Đôi Ta

Trang web tặng Huy.

## Đưa lên GitHub Pages

1. Tạo một repository mới trên GitHub (ví dụ `chuyen-doi-ta`).
2. Upload toàn bộ nội dung thư mục này: `index.html`, thư mục `img/`, và file `.nojekyll`.
3. Vào **Settings → Pages**, ở mục **Source** chọn **Deploy from a branch**, branch `main`, thư mục `/ (root)`, rồi **Save**.
4. Đợi 1–2 phút. Link sẽ có dạng `https://<tên-github>.github.io/chuyen-doi-ta/`.
